# Go 规范

适用于 `repos/` 下所有 Go 仓库。

## 规则

1. **字面量收敛**：重复出现两次以上的字面量提取为常量，沿用目标仓库命名风格。
2. **磁盘状态确认**：读取内容前，使用工具确认文件真实存在于磁盘。
3. **防御边界**：防御性代码仅覆盖真实发生的失败分支，禁止无边界防御。
4. **日志与错误文案**：`log.Msg()`、`errors.New()`、`fmt.Errorf()` 一律使用英文；中文仅限面向用户的 HTTP/UI 边界响应文案。
5. **测试分层**：遵守 `.agents/rules/tests.md` 端到端优先；并发时序使用 `-race` 与同步屏障，禁止随意编写微型单测。

## 检查

改动后立即执行，禁止攒批：

```bash
gofmt -w <改动文件>
go build ./...
go test -race ./...
```
