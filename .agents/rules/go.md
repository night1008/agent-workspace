# Go 规则

适用于 `repos/` 下所有 Go 仓库。

## 写代码

- 出现两次以上的字面量提成常量，命名沿用该仓库已有的常量模式。
- 注释规范见 `.agents/rules/comments.md`。
- 把 `read` 到的内容当依据之前，用 `ls` / `find` 确认文件确实在磁盘上。
- 防御性代码只覆盖真实会发生的失败路径。
- 改动范围停在当前需求内。

## 日志与错误文案

- `log.Msg()`、`errors.New()`、`fmt.Errorf()` 一律英文。中文只允许出现在面向最终用户的响应文案（HTTP message、前端 UI 文案）里，且要集中在边界处，不要散落到内部错误链。

## 测试分层

见 `.agents/rules/tests.md`：端到端优先，集成与单元测试默认不写。Go 里并发时序靠 `-race` 加屏障，同包测试沿用 `*_test.go`。

## 检查

每条改动后立即跑，不要攒到最后批量执行：

```bash
gofmt -w <改动过的文件>
go build ./...
go test ./...
```
